# Toolmingle Play — casual web games MVP

A TypeScript + Vite multi-page static site implementing the v1.2 design plan for **Zapdash** (first MVP) and **Prismerge**. All graphics are made from CSS and text glyphs; no external game assets, accounts, analytics, advertising, or backend are required.

This initial commit bootstraps the repository. The full MVP source will be added in the next commit.
